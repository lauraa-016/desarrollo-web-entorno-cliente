## 📌 Sobre este repositorio

Este repositorio reúne las actividades desarrolladas en el módulo de **Desarrollo Web en Entorno Cliente (DWEC)** durante el segundo curso del ciclo formativo de **Desarrollo de Aplicaciones Web**.

El contenido está centrado principalmente en la programación que se ejecuta en el navegador y en la creación de páginas web dinámicas e interactivas.

---

## 🎯 Objetivos

A través de los diferentes ejercicios y proyectos se trabajan conceptos relacionados con:

- ⚡ Programación con JavaScript.
- 🧠 Lógica de programación.
- 🌐 Manipulación del DOM.
- 🖱️ Gestión de eventos.
- 📝 Validación y tratamiento de formularios.
- 📦 Arrays y objetos.
- 🔄 Funciones y estructuras de control.
- 📄 Manipulación de datos.
- 🔗 Uso de APIs.
- 📋 Trabajo con JSON.
- 🧩 Desarrollo de interfaces interactivas.
- 🔧 Control de versiones con Git y GitHub.

🧪 Ejercicios

Cada ejercicio se encuentra organizado en su correspondiente carpeta.

Siempre que sea posible, se mantendrá una estructura similar a:

ejercicio01/
│
├── index.html
├── js/
│   └── script.js
├── css/
│   └── style.css
└── README.md

Esto permite mantener separado el HTML, CSS y JavaScript y facilita la lectura y mantenimiento del código.

🚀 Proyectos

Además de los ejercicios individuales, el repositorio podrá incluir proyectos más completos en los que se combinen diferentes conceptos del módulo.

Estos proyectos tendrán como objetivo aplicar los conocimientos adquiridos en situaciones más cercanas a un desarrollo web real.

📖 Aprendizaje

Este repositorio refleja el proceso de aprendizaje y evolución en la programación web del lado del cliente.

Los ejercicios parten de conceptos básicos de JavaScript y avanzan progresivamente hacia páginas web más dinámicas, interactivas y funcionales.
