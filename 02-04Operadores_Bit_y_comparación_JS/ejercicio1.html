Operadores de asignación en JavaScript

Sintaxis Nombre Significado Ejemplo
= Asignación x = y x = y
+= Suma y asignación x = x + y x += y
-= Resta y asignación x = x - y x -= y
*= Multiplicación x = x * y x *= y
/= División x = x / y x /= y
%= Módulo x = x % y x %= y
<<= Desplazamiento izquierda x = x << y x <<= y
>>= Desplazamiento derecha con signo x = x >> y x >>= y
>>>= Desplazamiento derecha sin signo x = x >>> y x >>>= y
&= AND bit a bit x = x & y x &= y
|= OR bit a bit x = x | y x |= y
^= XOR bit a bit x = x ^ y x ^= y
**= Potencia x = x ** y x **= y
&&= AND lógico Asigna si x es verdadero x &&= y
||= OR lógico Asigna si x es falso x ||= y
??= Asignación nula Asigna si x es null o undefined x ??= y
Desestructuración Asignación múltiple [a, b] = [c, d] [a, b] = [c, d]
