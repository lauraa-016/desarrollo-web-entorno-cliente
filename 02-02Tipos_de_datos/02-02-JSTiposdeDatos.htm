Cuestionario y Ejercicios Prácticos

3. ¿Qué etiqueta se utiliza para insertar código JavaScript en HTML?

Se utiliza la etiqueta <script>. Puede colocarse dentro de la sección <head> o antes del cierre de </body>.

4. ¿Qué ventajas tiene incrustar el código JavaScript en un archivo externo?

  • Reutilización de código: Varios documentos HTML pueden compartir el mismo archivo JavaScript.
  • Separación de conceptos: Separa el contenido/estructura (HTML) de la lógica de programación (JS).
  • Mantenibilidad: Es más fácil corregir errores o actualizar la lógica en un solo archivo centralizado.
  • Rendimiento y Caché: El navegador almacena el archivo .js en la memoria caché, reduciendo el tiempo de carga en páginas subsecuentes.

5. ¿Qué extensión suelen tener los archivos que contienen código JavaScript?

Tienen la extensión .js.

6. ¿Cómo se referencia un archivo .js en HTML?

Mediante el atributo src en la etiqueta <script>:
<script src="script.js"></script>

7. ¿Qué debe hacer si el archivo JavaScript se encuentra en otro directorio?

Se debe indicar la ruta relativa o absoluta adecuada en el atributo src:
  • Subdirectorio: <script src="js/script.js"></script>
  • Directorio superior: <script src="../js/script.js"></script>
  • Ruta absoluta o URL: <script src="https://ejemplo.com/js/script.js"></script>

8. ¿Qué etiqueta se usa para mostrar un mensaje si el navegador no soporta JavaScript?

Se utiliza la etiqueta <noscript>.
Ejemplo: <noscript>Este sitio requiere JavaScript para funcionar correctamente.</noscript>

9. ¿Qué diferencia hay al insertar JavaScript en XHTML?

En XHTML (al ser XML estricto), los caracteres como < y & pueden causar errores de sintaxis XML. Para evitarlo, el código embebido debe envolverse en una sección CDATA: 
// <![CDATA[
   // Código JavaScript aquí...
// ]]>
O alternativamente, utilizar archivos externos .js.

10. ¿Qué es la ofuscación de código y por qué se utiliza?

La ofuscación de código consiste en transformar el código fuente JavaScript para hacerlo de muy difícil lectura y comprensión para los seres humanos (renombrando variables a caracteres confusos, eliminando espacios, cambiando estructuras), manteniendo la misma funcionalidad lógica.
Se utiliza para proteger la propiedad intelectual, prevenir la ingeniería inversa no autorizada y reducir el tamaño del archivo (en conjunto con la minificación).

11. ¿Cómo se llama el lenguaje que se menciona en el texto?

El lenguaje es JavaScript (estandarizado como ECMAScript).

12. ¿Qué nombre le dio Microsoft a JavaScript?

Microsoft le dio el nombre de JScript.

13. ¿Por qué Microsoft usó el nombre JScript?

Debido a cuestiones de marcas registradas y derechos de autor. Sun Microsystems poseía la marca registrada "Java", y Netscape junto con Sun poseían los derechos de la marca "JavaScript". Para evitar litigios legales, Microsoft creó su propia implementación con el nombre JScript.

14. ¿Qué problema surgió con la versión de JScript de Microsoft?

Generó graves problemas de incompatibilidad entre navegadores (las "guerras de navegadores"). JScript incluía características propietarias que no funcionaban en Netscape Navigator (y viceversa), lo que obligaba a los desarrolladores a escribir diferentes versiones de código para cada navegador.

15. ¿Qué es el DOM y por qué fue diseñado?

El DOM (Document Object Model) es una API e interfaz de programación estándar que representa un documento HTML o XML como una estructura en árbol de objetos.
Fue diseñado para permitir a los lenguajes de programación (como JavaScript) acceder, modificar, añadir o eliminar de forma dinámica el contenido, la estructura y los estilos de un documento web de manera uniforme entre distintos navegadores.

16. ¿Qué navegadores incorporaron el DOM desde su primera versión?

Internet Explorer 4.0 y Netscape Navigator 4.0 incorporaron versiones iniciales e incompletas (DOM Nivel 0 / DHTML). La estandarización oficial del W3C (DOM Nivel 1) comenzó a ser adoptada plenamente a partir de Internet Explorer 5.0, Netscape 6.0 y posteriormente Mozilla Firefox.

17. ¿Qué estándar regula el lenguaje JavaScript desde 1997?

El estándar ECMA-262, mantenido por la organización ECMA International.

18. ¿Qué documento detalla las especificaciones del estándar ECMA?

El documento formal es la Especificación del Lenguaje ECMAScript (ECMAScript Language Specification - ECMA-262).

19. ¿Qué relación tiene JavaScript con Java?

Prácticamente ninguna relación técnica directa. Comparten una sintaxis similar basada en C y el término "Java" por razones puramente comerciales de marketing en 1995.
  • Java: Lenguaje de programación compilado, fuertemente tipado, basado en clases y ejecutado en la Máquina Virtual de Java (JVM).
  • JavaScript: Lenguaje de script interpretado/JIT, dinámico, de tipado débil, basado en prototipos y ejecutado principalmente en el navegador.

20. ¿Quién desarrolló originalmente JavaScript y con qué nombre?

Fue desarrollado por Brendan Eich en Netscape en 1995. Inicialmente se llamó Mocha, luego pasó a llamarse LiveScript, y finalmente JavaScript.

23. ¿Qué caracteres y nombres están prohibidos como nombre de variables?

  • Comenzar por un número: Ej. 123variable (Ilegal).
  • Espacios y caracteres especiales: Ej. mi variable, precio-total, año#, user% (Ilegal). Solo se permiten letras, dígitos, _ y $.
  • Palabras reservadas de JS: Ej. var, let, const, function, if, else, return, class, typeof, null, true, false, break, for, while, import, etc.

29. Declara varias variables con const e intenta cambiarlas y visualízalas con un alert, ¿qué pasa?

Explicación: Las variables declaradas con const son constantes de solo lectura y poseen ámbito de bloque. Al intentar reasignar su valor, el motor de JavaScript arroja un error no capturado de tipo TypeError: Assignment to constant variable y la ejecución del script se detiene inmediatamente.

30. Declara varias variables con var dentro de un bloque if al principio e intenta acceder a ellas dentro y fuera del bloque con un alert, ¿qué pasa?

Explicación: Las variables declaradas con var no tienen ámbito de bloque, sino ámbito de función (o global). Por tanto, son accesibles y visibles tanto dentro como fuera del bloque if.
